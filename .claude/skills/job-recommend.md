# /job-recommend

根据用户指定的岗位关键词，从本地知识库遍历全量岗位详情，结合画像做匹配推荐。

## 前置

### 知识库路径
```
/home/xstars/programs/JobSniper/storage_layer/positions/zhilian_intelligence_vault/
```

### 用户画像
使用 `find_job_detail` 或读取 vault 前，必须先读取 `mcp__mempalace__mempalace_kg_query(entity="魏同学")` 获取当前画像约束（薪资底线、地点、技能、目标方向）。

### 画像约束速查
| 维度 | 值 |
|------|-----|
| 地点 | 上海 |
| 薪资底线 | 12,000 元/月 |
| 目标方向 | AI产品经理 / AI应用工程师 / AI产品架构师 |
| 技能 | Python, C++, 前端, 微信小程序, RAG学习中 |
| 教育 | 二本旅游管理/计算机辅修 |
| 经验 | 3年少儿编程教培 |

## 执行流程

### 第 1 步：关键词解析

```
用户输入关键词
  ↓
读取 zhilian_master_tasks.json（路径: /home/xstars/programs/JobSniper/storage_layer/positions/zhilian_master_tasks.json）
  ↓
精确匹配 keyword 字段
  ↓
命中 → { keyword, industry, domain }
未命中 → 使用语义理解映射到 JSON 中最接近的 keyword
```

### 第 2 步：定位并遍历

```
路径: vault/{industry}/{domain}/{keyword}/
  ↓
排除 _ 开头的索引文件
  ↓
遍历所有剩余 *.md 文件，读取 YAML frontmatter 提取 title/salary/company/url
```

### 第 3 步：初筛

按硬约束淘汰：
- 薪资上限 < 12,000 元 → 剔除
- 学历硬性要求硕士/博士且无"可降低条件"说明 → 剔除
- 经验 > 5 年且无弹性措辞 → 标记低优先级
- 明确非上海地点 → 剔除

保留 30-50 个候选。

### 第 4 步：精选打分

对初筛候选读取完整`职位详情全文`，按以下维度打分：

| 维度 | 权重 | 判据 |
|------|------|------|
| 岗位契合 | 30% | JD 方向是否匹配目标岗位 |
| 技能匹配 | 25% | Python/C++/教育背景/小程序/RAG 是否被 JD 提及或可迁移 |
| 门槛友好 | 20% | 经验年限、学历弹性、"专业不限"、"理工科优先"等措辞 |
| 公司背书 | 15% | 上市公司/国企/知名企业加分 |
| 薪资水平 | 10% | 薪资上限 ≥ 1.5 万加分 |

取 Top 10-15。

### 第 5 步：画像定制输出

按匹配度分三档：

**S 档** — 画像完美契合（教培背景变现、技术栈精准匹配）
**A 档** — 强烈推荐（门槛友好、品牌背书、方向正确）
**B 档** — 备选（高门槛但可尝试，或低门槛保底）

每人每档推荐 3-5 个。

输出格式：
```
# [岗位关键词] — 画像匹配推荐

## S 档
### N. 公司 — 岗位名
| 维度 | 详情 |
|------|------|
...
> 匹配分析

## A 档
...

## B 档
...

## 投递优先级

| 优先级 | 岗位 | 理由 |
|--------|------|------|
...
```

### 第 6 步：新鲜度检查

岗位详情采集时间超过 7 天 → 末尾提示用户是否需要启动 `launch_zhilian_job_list_collection` 重新爬取。

## 注意事项

- **禁止使用 `find_job_detail` 做岗位推荐**：它只做文件名字面子串匹配，会遗漏大量结果
- 必须遍历目录下全部文件，不能以文件名筛选代替
- 若 vault 目录不存在或为空，提示用户先运行岗位列表采集
- 若用户未给出薪资/地点等约束，从画像 KG 中自动抓取
