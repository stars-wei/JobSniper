# 自适应详情页爬取工作流

## 触发场景

从岗位索引表中提取全部 URL，批量爬取智联招聘岗位详情页。

## 前置条件

- [ ] Chrome 已登录智联招聘账号
- [ ] 岗位索引表已归档至 knowledge_vault
- [ ] 提取的 URL 清单已保存

## 自适应降级阶梯

| 级别 | 并行数 | 批间间隔 | 触发条件 |
|------|--------|----------|----------|
| 正常 | 5 | 0s | 初始状态 |
| 一级 | 3 | 90s | 首次触发验证码 |
| 二级 | 1 | 180s | 第二次触发验证码 |
| 三级 | 暂停 | — | 第三次触发，等待手动过验证码 |

## 验证码检测方式

每批完成后检查 Downloads 目录：
- 对应 URL 的 detail 文件未写入 → 判定触发
- 文件内容为验证码页面 → 判定触发

## 执行流程

```
初始状态: 并行=5 间隔=0s
     │
     ▼
┌─────────────────────────────────┐
│  爬取一批 (N个URL并行Chrome)      │
│  等待下载完成                     │
│  检测: 是否触发验证码?            │
└──────────────┬──────────────────┘
               │
        ┌──────┴──────┐
        │             │
     未触发         触发验证码
        │             │
        ▼             ▼
  保持当前参数   ┌──────────────────┐
  继续下一批    │ 降级: 并行-2 间隔+90s│
        │      │ 记录已完成的URL       │
        │      └────────┬─────────┘
        │               │
        │        ┌──────┴──────┐
        │        │             │
        │     恢复继续      再次触发
        │        │             │
        │        ▼             ▼
        │   继续下一批   ┌──────────────────┐
        │               │ 再次降级: 并行=1    │
        │               │ 间隔+180s          │
        │               └────────┬─────────┘
        │                        │
        │                 ┌──────┴──────┐
        │                 │             │
        │              恢复继续      第三次触发
        │                 │             │
        │                 ▼             ▼
        │            继续下一批   ┌──────────────┐
        │                        │ 暂停, 通知用户  │
        │                        │ 手动过验证码    │
        │                        │ 过完后继续      │
        │                        └──────────────┘
        ▼
   ┌──────────┐
   │ 全部完成  │
   │ 一次性归档 │
   └──────────┘
```

## 三层防御叠加

| 层级 | 策略 | 作用 |
|------|------|------|
| 前置 | Chrome 默认 Profile 携带登录态 | 降低验证码触发概率 |
| 实时 | 自适应降级阶梯 | 触发后自动调整节流 |
| 兜底 | 断点续传 + 手动过验证 | 不丢进度 |

## 完成后操作

所有 URL 爬取完成后，执行：

```
archive_joblens_outputs(keyword="AI产品经理", platform="zhilian", since_minutes=600, dry_run=false, include_test=false)
```

detail 文件将自动按公司名归入 `产品/互联网产品经理/AI产品经理/` 目录。
