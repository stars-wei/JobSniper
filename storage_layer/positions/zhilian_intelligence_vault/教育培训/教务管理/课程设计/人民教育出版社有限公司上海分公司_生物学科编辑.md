# 职位详情：生物学科编辑

## 01. 核心原始描述 (JD)

其他要求

1. 政治面貌要求：中共党员优先

2. 年龄要求：45周岁及以下

3. 职称要求：中级及以上

4. 具有5年及以上教育、出版领域相关工作经验

5. 有教学经历者优先，有编辑资格证者优先

6. 具有较强的组织、协调、沟通能力和文字写作能力

二、**岗位职责**

1. 参与本学科地方教材、教辅图书的编写、编辑工作；

2. 参与本学科课程教材教学理论、教辅相关课题的研究工作；

3. 参与本部门地方教材、教辅图书的市场调研和培训工作；

4. 完成领导交办的其他相关工作。

## 02. 公司背景
人民教育出版社有限公司上海分公司（简称“人教上海公司”） 成立于 2023年，是人民教育出版社为强化在上海的业务支点、提升华东地区影响力设立的分支机构，地处上海市黄浦区福州路文化街。人教上海分公司依托人民教育出版社的平台和资源，专业从事外语教育类、中小学教育类、人文社科类图书的出版。 人教社，是教育部所属大型专业出版社，主持或参与制定了历次中小学各科教学大纲和课程标准；先后编研出版了十二套全国通用中小学教材和多套职业教育教材及师范院校教材；2012年以来承担了中小学国家统编道德与法治（思想政治）、语文和历史教材的编研出版任务；是国内唯一一家承担义务教育阶段盲、聋、培智等特殊教育学校教材编研出版工作的单位；为澳门特别行政区学校编研出版了品德与公民、历史、宪法教育等教材。人教社持续深耕教育出版，实施品牌拓展战略，深入推进全民阅读，出版物涵盖教材、教学参考书、教辅、学术著作、工具书、青少年读物、科普读物、国际汉语图书、期刊以及各类数字音像产品等。
