# 职位详情：课程设计

## 01. 核心原始描述 (JD)

岗位内容：

1. 设计和开发符合职业教育体系要求的课程；

2. 搜集、分析和总结各种教学数据和反馈信息，不断优化课程设计和教学效果。

3. 参加校内外教育培训和研讨会议，掌握最新的教育理念和技术手段。

4. 协助教研部门推进教育教学改革和创新。

**任职要求**：

1. 具备教育学、自动化、计算机科学等相关专业背景，良好的写作能力。

2. 熟练掌握课程设计软件和在线教育平台的操作技能，有创作课程的经验。

3. 具备数据分析和处理能力，关注教学效果和学生学习成果，不断提高课程质量。

4. 积极乐观，具备优秀的沟通能力和团队合作意识，能够适应快速变化的工作环境。

## 02. 公司背景
优艾智合（YOUIBOT）是全球领先的工业具身智能科技公司，致力于通过移动操作机器人驱动全球工业客户智能化变革，实现稳定、柔性、高效的生产。优艾智合为半导体、能源化工、电子、新能源等众多行业提供“一脑多态”具身智能机器人解决方案，包含高泛化智能模型以及具备感知、移动、操作能力的多形态机器人。目前，优艾智合国内市场覆盖26个省/直辖市/自治区，产品出口日本、韩国、新加坡、西班牙、德国、意大利等多个国家及地区，是全球头部半导体晶圆代工厂、国内两大电网集团和五大能源集团在内的众多工业企业的忠实合作伙伴。“优艾博特UIBOTED”负责“优艾智合YOUIBOT”品牌在教育领域的产教融合人才培养，致力于协助学校建设《具身智能应用技术》专业，为“优艾智合”行业用户培养专业应用型人才。
