# 职位详情：创新课程研发工程师（理工科）-创新教育

## 01. 核心原始描述 (JD)

**岗位职责**：

1. 专注于理工科领域的创新课程设计和开发，将最新技术（人工智能、机器学习、编程等）融合到课程设计和教学中，确保课程内容科学、实用，并融合最新科技趋势，提升教学质量和学习体验。

2. 负责课程教学，收集反馈，根据学生和教师的反馈不断优化课程。

3. 设计和实施针对各类学科竞赛的辅导方案，帮助学生提升竞赛水平。

4. 进行教育趋势研究和学习成效分析，确保课程内容的前沿性和创新性。

5. 与教育团队紧密合作，分享教学经验，收集反馈，不断调整和优化课程内容。

6. 管理课程开发、教学和竞赛辅导项目，确保按时、按质完成。

**任职要求**：

1. 重点院校硕士及以上学历，STEM专业。

2. 至少3年相关领域工作经验，包括课程设计、开发、教学实践和学科竞赛辅导。

3. 熟练掌握至少一种编程语言，了解教育技术工具和平台。

4. 优秀的团队合作和跨部门沟通能力。

5. 具有创新思维，能够有效传授知识，激发学生兴趣。
