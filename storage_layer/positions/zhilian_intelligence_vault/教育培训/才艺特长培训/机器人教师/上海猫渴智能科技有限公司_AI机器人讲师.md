## 职位详情全文

岗位职责 1.课程授课：负责 AI 玩具开发、智能硬件与大模型结合、智能体（Agent）基础应用、机器人基础控制（入门级）等相关课程的授课，确保课程按照教学计划高质量完成。 2.学员项目指导：指导学员完成实战项目，如基于树莓派 / ESP32 的 AI 智能设备开发、基于大模型 API 的语音交互系统、基础机器人功能实现（语音、动作控制等），并协助解决项目中的技术问题。 3.教学支持与课程优化：及时解答学员技术问题，收集教学反馈，配合课程研发团队持续优化课程内容。 4.技术学习与更新：持续关注 AI 及智能硬件相关技术发展，保持课程内容的先进性与实用性。 任职要求 1.学历与专业：本科及以上学历，计算机科学与技术、软件工程、自动化、电子信息工程、人工智能等专业优先，优秀应届毕业生亦可考虑。 2.技术基础要求：具备以下至少一项经验： 熟练使用 Python 进行开发 有智能硬件开发经验（树莓派 / Arduino/ESP32 等） 有 AI 应用开发经验（如调用大模型 API） 有机器人相关学习或项目经验 3.技术能力要求： 必须熟悉 Python 基础开发，能编写简单程序并完成基本功能实现 4.了解以下任意方向优先：ROS 或 ROS2 基础概念、智能体（Agent）应用基础、智能硬件开发基础、大模型 API 使用 5.不要求精通 C++，不要求复杂机器人开发经验 6.教学与表达能力：具备良好的沟通表达能力，能够清晰讲解技术内容；有教学、培训或技术分享经验者优先。 加分项（非必须） 开发过 AI 机器人项目 开发过 AI 玩具或智能硬件项目 使用过树莓派或 ESP32 有开源项目经验
